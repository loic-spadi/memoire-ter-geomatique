# Mémoire TER de Géomatique

Ce travail d'étude et de recherche de Master 1 de Géomatique consiste en une analyse de la structure socio-spatiale de l'ensemble des métropoles administratives françaises, se basant sur la théorie des capitaux initiée par Pierre Bourdieu. De plus, ce mémoire apporte un R-script automatisé du traitement pour l'application sur l'ensemble des métropoles du pays.

Ce dépôt est constitué :
  - Du rapport final avec l'intitulé du mémoire
  - De quelques figurés présentés dans le mémoire, réalisés sur R et sur QGIS
  - D'un script automatisé pour le traitement et également disponible en annexe dans le rapport
